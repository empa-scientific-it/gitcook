# Risotto Milanese JK

Copy this into a new `.mdx` file under `src/content/docs/`.
Remember to choose the right folder to place your recipe in.

## Quick Rules

- Recipe pages are MDX files inside `src/content/docs/`
- Use a lowercase, hyphenated file name such as `chocolate-chip-cookies.mdx`
- Put the file in the correct category folder
- Include `title`, `description`, `category`, and `ingredients` in the recipe details block at the top
- Use ingredient quantities where possible
- Import `Steps` from `@astrojs/starlight/components`
- Write the method inside the `<Steps>` block

## Template

```mdx
---
title: Risotto Milanese JK
description: This is how Jochen prepares the Risotto Milanese
category: Main-course
ingredients:
  - 8 dessertspoonful of rice for risottos
  - 200ml of vegetable stock
  - 1 sachet of saffron
  - 1 dessertspoonful of white wine
  - cheese
servings: 1
prepTime: 35 minutes
cookTime: 35 minutes
---

import { Steps } from '@astrojs/starlight/components';

## Instructions

<Steps>

1. Wash the rice and roast it gently

2. Gradually add the vegetable stock, let it simmer and stir constantly

3. Add the wine and the saffron, let it still simmer and continue stirring

4. Once the rice is firm to the bite, add the cheese and let it melt

5. Ready

</Steps>

## Tips

- Optional tip or variation
```
